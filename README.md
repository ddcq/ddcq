# 💫 About Me:
🔭 I'm currently working on: **ha-maid** (`camille`) — a 2D voice assistant in Rust with a manga avatar driven by webcam head-tracking (MediaPipe `face_landmarker`), Parakeet TDT v3 speech-to-text and Piper TTS, plugged into Home Assistant and Music Assistant<br>👯 I'm looking to collaborate on: Webcam-driven interfaces, local-first voice agents, and open source tooling for AI-assisted development<br>🤝 I'm looking for help with: On-device speech pipelines (STT/TTS quality vs latency), ESP32 voice hardware, and making head-tracking feel natural rather than jittery<br>🌱 I'm currently learning: Rust, ESP32/ESPHome and the Wyoming protocol, Parakeet/Sherpa-ONNX model tuning, and agentic engineering workflows<br>💬 Ask me about: MediaPipe head-tracking, Web Speech and Whisper alternatives, Piper/Parakeet local TTS-STT, Three.js and macroquad, Home Assistant custom components, Flutter clean architecture<br>🛠️ Recent things I shipped: **HeadGames** — two browser 3D games (a Space Invaders-style tank shooter and a procedural first-person maze) where the webcam steers the tank; a Wyoming-Protocol voice assistant for an ESP32-S3 "Ball v2" display; **ddcq-skills**, a set of Claude Code skills that gate changes through review, debug and security passes before they land; and a Python + GitHub Actions pipeline that renders my contribution calendar as animated-wave SVGs across 6 themes<br>⚡ Fun fact: The contribution calendar at the bottom of this profile is generated by my own script — I automated my own stats!
